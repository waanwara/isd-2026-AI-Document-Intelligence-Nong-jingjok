## 📐 โครงสร้างหน้าจอหลัก (Layout Structure)

### 1. ส่วนหัว (Header & Brand Banner)
- โลโก้ **Jingjok-Thorius** (มาสคอตน้องจิ้งจกทองหล่อสีส้ม KMITL)
- หัวข้อหลัก `JINGJOK-THORIUS` และคำบรรยายระบบ "ระบบถาม-ตอบหลักสูตร IT KMITL"

### 2. ส่วนเลือกหลักสูตรและคำถาม (Curriculum Selector & Query Input)
- **หลักสูตรที่เลือก (Curriculum Scope):** Dropdown เมนูแบบบังคับเลือก (IT, DSBA, AIT, BIT, AITBA) เพื่อให้คำตอบแม่นยำตรงตามสาขาวิชา
- **คำถามยอดฮิต (Quick Prompt Chips):** ปุ่มคำถามด่วนแนะนำ เช่น:
  - *หลักสูตร DSBA 2565 ต้องเรียนครบกี่หน่วยกิต*
  - *Data Warehouse ต้องผ่านวิชาใดก่อน*
  - *อยากจบ DSBA ภายใน 3.5 ปี*
- **กล่องข้อความพิมพ์คำถาม (Textarea):** รองรับภาษาไทย/อังกฤษ พร้อมตัวนับอักขระ (`0 / 800`) และข้อความแนะนำ (Placeholder)
- **ปุ่มดำเนินการ (Action Buttons):**
  - ปุ่มส่งคำถาม **"ถามจิ้งจก Thorius"** (สีส้ม Accent)
  - ปุ่ม **"ล้าง (Clear)"** สำหรับล้างข้อความในกล่องคำถาม

### 3. ส่วนแสดงสถานะและคำตอบ (Response & Provenance Display)
- **สถานะกำลังค้นหา (Loading Spinner):** ไอคอนแอนิเมชันหมุนพร้อมข้อความ "กำลังค้นหาข้อมูลหลักสูตร..."
- **กล่องแจ้งเตือนข้อผิดพลาด (Error Alert Box):** แสดงเมื่อไม่เลือกหลักสูตรหรือเกิดข้อผิดพลาดในการเชื่อมต่อ
- **การแสดงผลคำตอบ (Answer Card):**
  - แสดงคำถามที่ถามซ้ำ (Echoed Question)
  - ป้ายแสดงเวอร์ชันหลักสูตร (`DSBA 2565 (current)`)
  - ตัวจับเวลาประมวลผล (`⚡ 0.28s`)
  - เนื้อหาคำตอบ Markdown แสดงรายชื่อวิชา รหัสวิชา หน่วยกิตอย่างเป็นระเบียบ
  - **แถบ Citation Tags:** ป้ายกำกับอ้างอิง เช่น `DSBA 2565 หน้า 323` ที่สามารถคลิกเปิดหน้าต่างดูเนื้อหาเอกสารจริงได้
- **แผงตรวจสอบคำสั่ง SQL (Developer Accordion):**
  - กล่องแสดงคำสั่ง SQL ที่ระบบสืบค้นใน SQLite Provenance Store แสดงตรรกะการคัดกรองข้อมูลอย่างโปร่งใส

## 🎨 Design Tokens & UI Guidelines

- **Typography:** ฟอนต์ `Sarabun` (ภาษาไทยมาตรฐานราชการ ชัดเจน อ่านง่าย มีหัว) ผสานกับ `Inter` สำหรับตัวเลขอังกฤษและโค้ด
- **Color Palette:**
  - `Primary Brand Orange`: `#FF6600` (สีส้ม KMITL เอกลักษณ์)
  - `Deep Accent Orange`: `#C43D00` (ปุ่ม Hover และข้อความเน้น)
  - `Canvas Warm Cream`: `#FAF7F2` (พื้นหลังโทนอุ่น สบายตา)
  - `Surface Pure White`: `#FFFFFF` (การ์ดแสดงผลคำตอบ)
  - `Console Dark Navy`: `#1E293B` (พื้นหลังส่วนแสดงโค้ด SQL)
