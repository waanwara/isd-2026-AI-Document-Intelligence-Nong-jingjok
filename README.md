# Jingjok-Thorius (น้องจิ้งจก-ทองหล่อ)

ระบบถาม-ตอบหลักสูตรคณะเทคโนโลยีสารสนเทศ สจล. จากเล่ม มคอ.2 จำนวน 14 เล่ม (3,689 หน้า, 5 หลักสูตร: IT, DSBA, AIT, BIT, AITBA)
เลือกหลักสูตร พิมพ์คำถามภาษาไทย แล้วได้คำตอบพร้อมเลขหน้าที่อ้างอิง และดูคำสั่ง SQL ที่ใช้ดึงข้อมูลได้

## วิธีใช้งานครั้งแรก

ทดสอบบน Windows 10/11 ใช้ Python 3.11 (โปรเจกต์กำหนด `>=3.11,<3.12`)

**1. ติดตั้ง Python 3.11** จาก python.org และติ๊ก "Add python.exe to PATH" ตอนติดตั้ง

**2. ติดตั้งไลบรารี** เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน

```
pip install -r requirements.txt
```

ขั้นนี้ดาวน์โหลด `torch` (ใช้ CPU ได้ ไม่ต้องมี GPU) จึงใช้เวลาหลายนาที

**3. ใส่ API key** คัดลอก `.example.env` เป็น `.env` แล้วแก้บรรทัดนี้

```
TYPHOON_API_KEY=ใส่คีย์ของคุณ
```

สมัครฟรีที่ https://opentyphoon.ai คีย์ใช้สำหรับคำถามเชิงเหตุผล เช่น "ลงวิชานี้ปีสองได้ไหม" ถ้าไม่ใส่ ระบบยังตอบคำถามที่มาจากตารางได้ (ปี/ภาค, วิชาบังคับก่อน ฯลฯ) แต่คำถามเชิงเหตุผลจะได้หลักฐานดิบแทนคำตอบสรุป

**4. เปิดระบบ** ดับเบิลคลิก `start.bat` ครั้งแรกมันจะทำสองอย่างให้เอง

- แตกไฟล์ฐานข้อมูล `artifacts/katrag.sqlite3.gz` เป็น `katrag.sqlite3` (~110 MB)
- ดาวน์โหลดโมเดล `BAAI/bge-m3` (~2.3 GB ต้องต่ออินเทอร์เน็ต ใช้เวลาตามความเร็วเน็ต)

จากนั้นเบราว์เซอร์จะเปิดที่ http://127.0.0.1:8000/ ให้อัตโนมัติ คำถามแรกอาจช้าประมาณ 1 นาทีเพราะต้องโหลดโมเดลเข้าหน่วยความจำ คำถามถัดไปเร็วขึ้นมาก

**5. ใช้งาน** เลือกหลักสูตรจาก dropdown พิมพ์คำถามหรือกดคำถามตัวอย่าง แล้วกด "ถามจิ้งจก Thorius"

ปิดระบบด้วย `Ctrl+C` ในหน้าต่างที่เปิดค้างไว้

### macOS / Linux

```
pip install -r requirements.txt
cp .example.env .env          # แล้วใส่ TYPHOON_API_KEY
python setup_db.py            # แตกฐานข้อมูล
python setup_model.py         # ดาวน์โหลด bge-m3
python -m uvicorn katrag.api.service:app --host 127.0.0.1 --port 8000
```

- C3 (แผนปกติ vs สหกิจ): ตอนนี้ตอบจากตารางแผนทั้งสองชุดในเล่ม (ต่างกันที่ปี 4 ภาค 1 และภาค 2 รวมทั้งหลักสูตรเท่ากัน 132) ตรวจกับเล่มแล้วถูก แต่เฉลยในไฟล์ทดสอบคลาดเคลื่อน: เขียนว่าแผนปกติลงโครงงาน 2 ที่ปี 4 ภาค 2 ทั้งที่เล่มวางไว้ปี 4 ภาค 1 ทั้งสองแผน และใช้รหัสสหกิจ 06026245 (ในเล่มคือ 06026259/06026260) จึงตัดสินตามเล่ม
- M8 ตอบจากตาราง rule แล้ว (ได้ 12 และ 6 ตรงเฉลย ตอบคงที่ทุกรอบ) ก่อนหน้านี้ผ่าน LLM ถามซ้ำ 8 รอบได้ 12 เพียง 5 ครั้ง
- ผลตรวจเทียบกับเฉลยในไฟล์ทดสอบ ไม่ได้เทียบกับ PDF ต้นฉบับโดยตรง คำตอบของข้อที่เรียก LLM เปลี่ยนได้ทุกรอบ (เช่น H2) ข้อที่ตอบจากตาราง SQL ได้คำตอบเดิมทุกครั้ง ข้อที่ผ่าน LLM 2 ข้อ (H2 5.4 วินาที, C1 7.5 วินาที) ใช้เวลาเกิน 5 วินาทีในรอบที่บันทึก
- ตัวตรวจ "คำสำคัญ" ในสคริปต์หลวม (ผ่าน 28/28) จึงไม่ใช้เป็นอัตราความถูกต้อง
- ความถูกต้องของ citation วัดแยก (19 ข้อ, `python -m katrag.eval.qa_eval`): precision 0.60, recall 0.50 (precision ขึ้นเพราะคำตอบจากตาราง rule/แผนอ้างหน้าตรง; recall ขยับตามคำตอบที่ผ่าน LLM; retrieval hit 17/19 เท่าเดิม)
- ข้อมูลที่สกัดเทียบเฉลยอาจารย์ (272 วิชา): ชื่อไทย 91.9%, ชื่ออังกฤษ 92.6%, หน่วยกิต 99.6%, ชั้นปี 97.9%, ภาค 100% (วัดบนหน้าที่ใช้ text layer ทั้งหมด ไม่ใช่ผล OCR)
- OCR (Tesseract) อ่านตัวอักษรได้ CER 4.5% (วัดแบบ paired-page 56 หน้า) ส่วนใหญ่ที่ผิดคือลำดับการอ่านในหน้าตาราง

### ชุดเพิ่มระดับง่าย / กลาง / ยาก (24 ข้อ)

เขียนคำถามเพิ่มอย่างละ 8 ข้อ ข้ามหลักสูตร IT, BIT, AIT, DSBA แล้วตรวจเฉลยกับหน้าในเล่ม (ข้อ E10–H15 ในแผ่น "All Test Cases & Results", ข้อมูลใน `docs/extra_levels.json`) รอบแรก **ก่อนแก้ระบบ** ได้ ถูก 14 · ไม่ตรงประเด็น 4 · ผิด 6 (ข้อยากถูกแค่ 2 จาก 8) จึงแก้แล้วรันซ้ำ ชุดนี้ใช้นำการแก้ จึงไม่ใช่ชุดที่ซ่อนไว้วัด

| :--- | :---: | :---: | :---: | :---: |
| ง่าย | 8 | 8 | 0 | 0 |

ที่แก้: ถามย้อนทิศ prerequisite (วิชานี้เป็นต้นทางของวิชาไหน), หน่วยกิตรวมต่อภาคอ่านจากบรรทัด "รวม" ในหน้าแผน, ตอบ "ไม่พบวิชานี้ในหลักสูตร" เมื่อชื่อวิชาไม่ตรงกับวิชาใดของหลักสูตรนั้น, ผูกคำถามกับหลักสูตรและระดับปริญญาที่เลือกให้ถูก (เดิมวิชาของ ป.โท หรือหลักสูตรอื่นปนเข้ามา), จับสำนวนถามหน่วยกิตรวมให้ครอบคลุมขึ้น และแก้ตัวสกัดตารางแผนให้หน้าที่ต่อจากตารางข้ามหน้าใช้ปี/ภาคของหน้าก่อน (IT 2565 วิชาปี 3 ภาค 2 สามวิชาเคยถูกวางไว้ปี 4) ปรับฐานข้อมูลใน `artifacts/katrag.sqlite3.gz` แล้ว

ต่อมาเพิ่มอีก 2 อย่างเพื่อแก้ข้อที่ยังพลาด: (1) ตารางหน่วยกิตรายหมวด/กลุ่มวิชาในตาราง `rule` (89 ค่า จาก DSBA/IT/BIT/AIT ฉบับปัจจุบัน และ DSBA/IT/BIT ฉบับ 2560 อ่านจากหน้าโครงสร้างหลักสูตร ทุกค่าตรวจเทียบข้อความในหน้านั้นก่อนบันทึก) ตอบคำถามเช่น "หมวดวิชาเฉพาะเลือกเก็บกี่หน่วยกิต" และตรวจเกณฑ์จบรายหมวดของ AIT (H11) จาก SQL (2) อ่านตารางแผนปกติและแผนสหกิจจากเล่มโดยตรง (`katrag/query/plan_variants.py`) ผลรวมหน่วยกิตทุกภาคของทั้งสองแผนตรงกับหน่วยกิตรวมของหลักสูตรทั้ง 6 เล่มที่มีแผนสหกิจ ตอบ X4, X8, Y4, Z3 และ C3 ได้

ที่ยังไม่ดี: M11 (นับวิชา Machine Learning ตามความหมาย ไม่มีเฉลยตัวเลข), M14 (IT ปี 3 ภาค 1 เรียกวิชาเลือกในโมดูลอาชีพว่า "วิชาบังคับ" และไม่มี 06066102)

### ชุดจาก tester (T1–T10)

ผู้ทดสอบแจ้งว่า คำถามเจาะจงวิชาตอบไม่ได้ (เช่น "fundamental web programming เรียนตอนไหน"), หลักสูตรที่มีแขนงย่อย (DSBA) และโมดูล (IT) ตอบรายวิชาไม่ครบหรือผิดกลุ่ม, อาจารย์ประจำหลักสูตรไม่ครบ (และ IT ได้อาจารย์ ป.โท มาแทน), เลขประจำตัวประชาชนอาจารย์หลุด และมีอักษรจีนปนในคำตอบ แก้ดังนี้ (ทั้งหมดไม่ได้เขียนคำตอบเฉพาะข้อลงโค้ด):

- `katrag/query/course_groups.py` อ่านจากหัวข้อรายวิชาในเล่มว่าแต่ละวิชาอยู่กลุ่ม/แขนง/โมดูลใด (วิชาเดียวอยู่ได้หลายกลุ่ม เช่น IT 06016418) แล้วตอบ "วิชา X เรียนตอนไหน" (ปี/ภาคจากตารางแผนของทั้งสองแผน หรือช่องวิชาเลือกที่ลงได้ถ้าเป็นวิชาเลือก) และ "แขนง/โมดูล Y มีวิชาอะไร" ปิดไว้สำหรับเล่มที่หาจุดสิ้นสุดของหัวข้อรายวิชาไม่เจอ (AIT) แทนที่จะเดา
- `katrag/query/faculty.py` อ่านรายชื่ออาจารย์ผู้รับผิดชอบ/ประจำหลักสูตร/ผู้สอนจากหัวข้อ 3.2.1–3.2.3 ของเล่ม เลือกเวอร์ชันตามระดับปริญญาที่ถาม
- เลขประจำตัวประชาชน 13 หลักถูกปิดก่อนส่งให้ LLM, ในคำตอบ และในข้อความหลักฐานที่ API คืน
- ถ้า LLM ตอบปนอักษรจีน/ญี่ปุ่น/เกาหลี (เล่มไม่มีอักษรเหล่านี้เลย) ระบบถามใหม่หนึ่งครั้ง ถ้ายังปนอยู่จะตัดอักษรนั้นทิ้ง

ผล: เขียนคำถาม 10 ข้อจาก comment เหล่านี้พร้อมเฉลยจากเล่ม ตอบถูกครบ 9 ข้อ ข้อ T10 (ประวัติการศึกษาของอาจารย์) ตอบเฉพาะวุฒิปริญญาตรี ขาดปริญญาโท/เอก แต่ไม่มีเลขประจำตัวหลุด ตรวจคำตอบทั้ง 92 ข้อแล้วไม่พบเลข 13 หลักหรืออักษรจีน ชุดนี้เขียนขึ้นเพื่อนำการแก้ จึงไม่ใช่ชุดซ่อนวัด

### ข้อท้าทายเพิ่มเติม (20 ข้อ)

| ชุด | บทบาท | ก่อนแก้ระบบ | ผลล่าสุด (ถูกครบ / บางส่วน / ผิด) |

| Y (6 ข้อ) | เขียนไว้ก่อนแก้รอบที่ 1 | รอบ 1 วัดได้ 3 / 0 / 3 | 6 / 0 / 0 |
| Z (6 ข้อ) | เขียนไว้ก่อนแก้รอบที่ 2 | รอบ 2 วัดครั้งแรก 5 / 0 / 1 | 6 / 0 / 0 |

สิ่งที่แก้ (ทั่วไป ไม่ได้เขียนคำตอบลงโค้ด): เพิ่มหน่วยกิตรวมของทุกหลักสูตรปริญญาตรีรวมฉบับเก่าเข้าตาราง `rule` พร้อมหน้าที่มา, ตัวเทียบหน่วยกิตข้ามเวอร์ชัน, ให้การค้นหาครอบคลุมทุกเวอร์ชันที่คำถามระบุ, แก้ตัวสกัดวิชาบังคับก่อนที่ตกหล่นเมื่อมี 2 วิชา และแสดงวิชาบังคับก่อนหลายชั้น, กันคำถามเรื่องแผนการเรียน/บัณฑิตศึกษาไม่ให้ถูกส่งไปค้นรายชื่อวิชาผิดประเภท ผล 19 ข้อของ `qa_eval` และ consistency check (error 0) เท่าเดิม

รันซ้ำเอง: เปิดเซิร์ฟเวอร์แล้ว `python run_live_qa_tests.py` (หรือ `--replay docs/reviewed_run.json` เพื่อสร้างรายงานจากคำตอบรอบที่ตรวจไว้โดยไม่ต้องเปิดเซิร์ฟเวอร์) ผลตรวจโดยคนอยู่ใน `docs/manual_review.json` ผูกกับข้อความคำตอบ ถ้าคำตอบเปลี่ยน ข้อนั้นจะขึ้นว่า "ยังไม่ได้ตรวจ"

**ประวัติ:** เดิมข้อ M8, H5, C1, C3 ตอบด้วยข้อความสำเร็จรูปที่เขียนไว้ในโค้ด ทำให้ผลดูเป็น 28/28 ถูกถอดออกแล้ว ผลข้างบนคือผลของระบบจริง

## ข้อจำกัดที่รู้

- ประเภทวิชาของ IT ปี 3 ภาค 1 ยังเรียกวิชาเลือกในโมดูลอาชีพว่า "วิชาบังคับ" (M14) การเปรียบเทียบที่ต้องอธิบายโครงสร้าง (แขนง/โมดูล) ยังขึ้นกับ LLM และ AIT ยังตอบกลุ่มวิชา/แขนงไม่ได้ (รูปแบบเล่มต่างจากหลักสูตรอื่น) ส่วนการถามรายวิชาทั้งหลักสูตรให้ครบยังทำไม่ได้ เพราะตัวสกัดรายวิชายังไม่สมบูรณ์
- ผลของข้อที่ตอบจากตารางแผน/โครงสร้างยืนยันกับเล่มของ DSBA, IT, BIT, AIT ฉบับปัจจุบันและ 2560 เท่านั้น ส่วนปริญญาโท/เอกไม่มีตารางนี้
- ประเภทวิชา (บังคับ/เลือก) ของ AIT และ IT ยังสกัดผิดบางส่วน เพราะดึงวิชาเกินจริงเข้ามา (AIT 366 วิชา ทั้งที่หลักสูตรมีราว 120-150)
- คำตอบไวต่อสำนวนคำถาม เพราะจับประเภทคำถามด้วยกฎและคำสำคัญ
- คำถามเชิงเหตุผลต้องมีอินเทอร์เน็ตและ Typhoon API key ส่วนการค้นหาและฐานข้อมูลทำงานในเครื่อง
- API บางส่วนยังไม่สมบูรณ์ ดูหัวข้อ API

## โครงสร้างระบบ

```
เบราว์เซอร์ (web/)  ->  FastAPI (katrag/api/service.py)
                              |
                    katrag/query/pipeline.py
          ┌───────────────────┼───────────────────┐
   Structured SQL       Hybrid search          Typhoon LLM
 (ตาราง course ฯลฯ)   (FTS5 + bge-m3, RRF)   (สรุปคำตอบเชิงเหตุผล)
          └───────────────────┼───────────────────┘
                    SQLite (artifacts/katrag.sqlite3)
```

ขั้นตอนทำฐานข้อมูล (ทำไว้แล้ว ไม่ต้องรันใหม่): อ่านแต่ละหน้าด้วย PyMuPDF (text layer) หรือ Tesseract 5 (หน้าที่เป็นภาพ) -> จัดเรียงภาษาไทย -> สกัดรายวิชา/วิชาบังคับก่อน -> ตัดเป็น chunk -> ทำดัชนี FTS5 และ embedding bge-m3 ข้อมูลทุกแถวผูกกับเอกสาร/หน้า/พิกัด (provenance)

การทำงานของ `/ask`: ถ้าคำถามตรงกับประเภทที่ตอบจากตารางได้ (ปี/ภาค, วิชาบังคับก่อน, เกณฑ์จบ DSBA ที่ผู้ถามให้ตัวเลขมา, เทียบรายชื่อวิชาข้ามเวอร์ชัน) จะตอบจาก SQL ตรง ๆ ไม่ผ่าน LLM ถ้าไม่ตรงจะค้นแบบ hybrid แล้วให้ Typhoon เรียบเรียง

โฟลเดอร์หลัก

| โฟลเดอร์/ไฟล์ | หน้าที่ |
| :--- | :--- |
| `katrag/ingest/` | อ่านเล่ม, OCR, จัดเรียงภาษาไทย, สกัดรายวิชา |
| `katrag/query/` | pipeline ตอบคำถาม, structured query, hybrid retrieval, เรียก Typhoon |
| `katrag/api/` | FastAPI service |
| `katrag/eval/` | สคริปต์วัดผล (OCR, ฟิลด์, QA, citation, consistency) |
| `web/` | หน้าเว็บ (HTML/CSS/JS) |
| `config/` | ค่าตั้งค่า (`katrag.toml` ฯลฯ) |
| `docs/` | `tester.xlsx` และผลตรวจ, `er_diagram.md` (แผนภาพ ER), `removed_subsystems.md` (โค้ดที่ถอดออกและเหตุผล) |
| `tests/` | เทสต์ (`python -m pytest tests`) |

สร้างฐานข้อมูลใหม่จาก PDF (ไม่จำเป็นสำหรับการใช้งาน): วาง PDF ใน `Information_Technology_Course/` แล้วรัน `python -m katrag.cli preflight`, `python -m katrag.cli ingest`, `python -m katrag.cli index` (ต้องติดตั้ง Tesseract 5 ด้วย)

## API

เซิร์ฟเวอร์ผูกที่ `127.0.0.1:8000` เท่านั้น

| Method | Path | หน้าที่ | Status |
| :---: | :--- | :--- | :---: |
| POST | `/ask` | ถามคำถาม ได้คำตอบ + citation + SQL | 200, 422, 504 |
| GET | `/documents` | รายชื่อเอกสาร (**ยังไม่ได้ต่อกับฐานข้อมูล คืนรายการว่าง**) | 200 |
| GET | `/pages/{citation_id}` | หน้าที่ถูกอ้างอิงของคำตอบล่าสุด (`bbox` เป็น `null`) | 200, 404 |
| GET | `/traces/{request_id}` | สถิติของคำขอ (เก็บใน memory) | 200, 404 |

**Request** (`question` ยาว 1-2,000 ตัวอักษร, `program` เป็น `IT`, `DSBA`, `AIT`, `BIT` หรือ `AITBA`)

```json
{ "question": "วิชา data warehouse ต้องผ่านวิชาใดก่อน และวิชานั้นเรียนตอนไหน", "program": "DSBA" }
```

**Response 200** (ผลจริง ตัดรายการ citation และ SQL ให้สั้นลง)

```json
{
  "request_id": "bc0b3e33-65b3-4d55-ba86-46d66d6f1d02",
  "answer": "วิชา 06026212 การสร้างคลังข้อมูล (DATA WAREHOUSING) — 3(2-2-5) | ปีที่ 3 ภาคการศึกษาที่ 1\n  ต้องผ่านวิชาบังคับก่อน:\n    • 06066300 แนวคิดระบบฐานข้อมูล (DATABASE SYSTEM CONCEPTS) — 3(2-2-5) | ปีที่ 2 ภาคการศึกษาที่ 1",
  "citations": [
    { "citation_id": "cite-001", "document_id": "a39d6db17ccc5cf4", "page": 323, "heading": "ตารางรายวิชา/แผนการศึกษา" },
    { "citation_id": "cite-002", "document_id": "a39d6db17ccc5cf4", "page": 18, "heading": "ระบบสารสนเทศเพื่อการจัดการ" }
  ],
  "versions_resolved": ["DSBA 2565 (current)"],
  "citations_removed": 0,
  "unsupported_claims": 0,
  "total_time_seconds": 0.1881,
  "sql_query": "-- Query 1 SELECT code, name_th, name_en, credits_raw, year, semester, ... FROM course WHERE ..."
}
```

หมายเหตุ
- `citations_removed` และ `unsupported_claims` สงวนไว้สำหรับตัวตรวจ citation ที่ยังไม่ได้ต่อสาย ค่าเป็น 0 เสมอ
- `citation_id` (`cite-001`, ...) เก็บใน memory และถูกเขียนทับทุกครั้งที่ถามใหม่ `/pages` จึงใช้ได้กับคำตอบล่าสุดเท่านั้น
- 422 เมื่อ input ผิด (เช่น `program` ไม่อยู่ในรายการ จะได้ `"msg": "ต้องเลือกหลักสูตรก่อนถาม — ค่าที่รับได้: ..."`) 504 เมื่อเกิน 120 วินาที ถ้าเกิดข้อผิดพลาดภายใน ระบบคืน 200 พร้อมข้อความ `เกิดข้อผิดพลาด: ...` ในฟิลด์ `answer`

## หน้าเว็บ (4 สถานะ)

ไฟล์ `web/index.html`, `web/style.css`, `web/app.js` (HTML/CSS/JS ล้วน เรียก `/ask` ด้วย `fetch()`) ภาพ wireframe อยู่ที่ [`wireframe/wireframe-jingjok.png`](wireframe/wireframe-jingjok.png) และคำอธิบายใน [`wireframe/README.md`](wireframe/README.md)

| สถานะ | เมื่อไร | หน้าจอแสดงอะไร |
| :--- | :--- | :--- |
| Idle | เปิดหน้าเว็บ / กดล้าง | เลือกหลักสูตร, คำถามตัวอย่าง, กล่องพิมพ์พร้อมตัวนับ 0/800 |
| Loading | กดส่งคำถาม | spinner และปุ่มส่งถูกปิดกันกดซ้ำ |
| Success | ได้ 200 | คำตอบ (Markdown), ป้ายเวอร์ชันและเวลา, ชิปอ้างอิงหน้า (คลิกดูเนื้อหา), แผงพับดู SQL, ปุ่มคัดลอก |
| Error | ไม่เลือกหลักสูตร / 422 / 504 / เครือข่ายขัดข้อง | แถบเตือนพร้อมข้อความภาษาไทย แก้คำถามแล้วลองใหม่ได้ |
